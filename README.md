# ELEE-1144-M02-2026-27-Assignment

## Description
Design and implement an automated block storage and retrieval system using a Dobot Magician® robotic arm controlled by an ATmega328P microcontroller through low-level serial communication.
A set of wooden blocks will be provided for use in the project

## System Requirements
Your system must satisfy the following requirements:

•	The system must recognise three different types of wooden block.
•	Block types may be distinguished using either: 
    •	colour; or
    •	a coded marking.
•	All block types will be the same physical size.
•	A sensor system must be designed and implemented to detect and identify the different block types.
•	Each block type must be stored in a separate designated stacking area.
•	The system must be capable of storing up to three blocks of each type and prevent storage beyond this capacity.
•	The loading area may be designed and equipped with any sensors that the group considers appropriate.
